# MindCompass Knowledge Base

This directory contains the approved educational materials used
by the MindCompass RAG pipeline.

## Directories

- `pdf/` — Educational PDF documents.
- `notebooks/` — Jupyter Notebook learning materials.

The ingestion pipeline extracts, cleans, chunks, embeds, and
indexes these materials in ChromaDB.

Raw learning materials are excluded from GitHub. Team members
should obtain them through the agreed shared source.
